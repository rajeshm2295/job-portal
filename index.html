Download & Install

The fastest way to put anything on the internet.

WindowsAgentDetected

1

Install the ngrok agent

For the most secure experience, use the Microsoft Store to install ngrok.

Install from Microsoft Store

Install ngrok via WinGet with the following command:

winget install ngrok -s msstore

Install ngrok via Scoop with the following command:

scoop install ngrok
We recommend the Microsoft Store instead
The Microsoft Store install updates itself, and Windows Defender sometimes flags a directly downloaded ngrok.exe by mistake. Download the executable only when the Store isn’t an option. Learn why this happens.

Download a standalone executable with zero run time dependencies.

2

Add your authtoken

ngrok config add-authtoken "<YOUR_AUTHTOKEN>"

Don’t have an authtoken? Sign up for a free account.

3

Start an endpoint

ngrok http 80

80 is an example port. Use your app’s actual port. View docs for more info.

Open your ngrok URL in a browser to see it working!
